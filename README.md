# StayPoint – Hospitality Booking Analytics

## Project Overview
StayPoint is a SQL-based hospitality analytics project focused on analyzing hotel booking data to understand booking trends, guest behaviour, hotel performance, cancellations, and operational insights.

The project uses SQL queries to transform booking data into meaningful insights that can support better business decisions in the hospitality industry.

## Project Objectives
- Analyze hotel booking trends and patterns.
- Understand guest behaviour and booking preferences.
- Evaluate hotel and room performance.
- Analyze booking cancellations and no-shows.
- Identify useful business insights from hospitality data.

## Dataset Overview
The project dataset covers hotel bookings, stays, and guest information across multiple hotels.

## Analysis Performed
- Booking trends and demand analysis.
- Guest behaviour analysis.
- Hotel performance analysis.
- Room and staff performance analysis.
- Cancellation and no-show analysis.

## Tools & Technologies
- SQL
- Relational Data Analysis
- Data Aggregation
- Data Cleaning and Analysis

## SQL Concepts Used
- SELECT and WHERE
- GROUP BY and ORDER BY
- Aggregate Functions
- JOINs
- CASE WHEN
- Subqueries
